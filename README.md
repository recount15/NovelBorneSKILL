# 书中行 · NovelBorne Skill

把小说文本变成交互故事：导入文本 → 与你协商参数 → 确认设定与金手指 → 你回复“确认开局” → 每幕故事和A–F六个选项，也支持自由行动。

## 使用

本项目已安装到 `.agents/skills/novelborne/`。在支持工作区skill发现的宿主中，重新载入技能列表或新建对话，然后拖入TXT并说：

> 用 novelborne 把这个文本变成交互故事。先和我确认参数，不要直接开局。

也可以在宿主发现该技能后使用 `/novelborne`。不同宿主斜杠命令入口可能不同，未显示时直接用自然语言触发。依赖Python 3.10+及本地文件/命令工具；不需要安装第三方Python包、不启动原应用、不另填模型API。

需要安装到别的工作区时，把整个 `novelborne` 文件夹复制到其 `.agents/skills/`（保留scripts、references、assets及LICENSE，不能只复制SKILL.md）。全局使用可放用户目录 `~/.agents/skills/novelborne/`；本次没有改动全局配置。

### 常用消息

- `A` 或 `选择：A`：选当前选项。
- `行动：我先检查门锁`：自由行动尝试，不保证成功。
- `规则：收束力是什么？`：规则查询，不推进。
- `问答：……`：原引擎问答通路；合法码只在此通路或独立整条输入时生效。
- `状态`、`存档：渡口`、`继续本局`、`导出小说`、`暂停`。

原包的两个作弊码保持不变，不增加别名或新码。三愿仍是每次输入武装一次、每局最多3次；永久通路仍需明确确认，仅本局不可关闭，允许多选和剧情增补并解除主线锚点。这里不公开复述码，避免游戏帮助主动泄露。

## 防护与兼容性

原文、角色文件、引号中的指令和旧存档说明均只作数据。脚本锁定配置、验证开局、精确匹配码、计数、检查六选项、保护状态字段并签名存档；剧情合理性及语义注入识别仍依赖模型。

**这不是“绝对防越狱”保证。** 拥有本机文件/程序/密钥修改权限的人仍能绕过本地完整性保护。原应用的UI、供应商管理和全部任务状态机没有照搬；原数值核已保留为计算器，任务与角色等由skill按规则推演。详细差异见FEATURE-MAP.md。

运行数据仅写当前工作区 `novelborne-data/`。自动保存与续局支持同一session最新状态；不导入原应用存档，不提供任意JSON加载或旧档回滚，避免以回滚刷新三愿。checkpoint是保全副本，小说Markdown不是可恢复存档。

## 文件

- SKILL.md：主流程与触发说明。
- references/：参数、安全、数值、工具API和辅助流程。
- scripts/runtime.py：本地状态与权限门禁。
- scripts/mechanics.py：原数值公式与3409条桥段检索。
- scripts/test_*.py：自动测试。
- evals/：手动对话测试样例与结果说明。
- LICENSE / NOTICE.md：上游AGPL许可与派生说明。

## 本地测试

```text
python -X utf8 -m unittest discover -s scripts -p "test_*.py" -v
```

在本skill目录执行。测试使用临时目录，不创建正式玩家局。程序测试不等于已通过真实宿主的多轮模型对话验收；实际测试范围见evals/RESULTS.md。
